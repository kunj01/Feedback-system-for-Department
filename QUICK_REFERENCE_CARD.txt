┌─────────────────────────────────────────────────────────────────────────┐
│ 📅 ADMIN: HOW TO SET FEEDBACK PERIODS                                   │
└─────────────────────────────────────────────────────────────────────────┘

1. Go to: Forms Management → Click on any form
2. Configure period:
   ┌──────────────────┬────────────────────────────────────────────────┐
   │ Start Date/Time  │ When form becomes available (optional)         │
   │ End Date/Time    │ Submission deadline (optional)                 │
   │ Grace Period (h) │ Extra time after deadline: 0-168 hours         │
   └──────────────────┴────────────────────────────────────────────────┘
3. Select students → Click "Assign to Selected Students"

┌─────────────────────────────────────────────────────────────────────────┐
│ 🎨 STATUS BADGES                                                        │
└─────────────────────────────────────────────────────────────────────────┘

  🔵 Upcoming      → Not started yet (button disabled)
  🟢 Active        → Currently accepting submissions (can submit)
  🟡 Grace Period  → After deadline, still accepting (can submit)
  🔴 Ended         → Completely closed (button disabled)

┌─────────────────────────────────────────────────────────────────────────┐
│ 🔔 AUTOMATIC REMINDERS                                                  │
└─────────────────────────────────────────────────────────────────────────┘

  Students receive notifications:
  ✓ 24h before form opens       (if start_date set)
  ✓ 3 days before deadline      (if end_date set)
  ✓ 1 day before deadline       (if end_date set)
  ✓ 2 hours before deadline     (final reminder)

  Command: php artisan feedback:send-reminders (runs hourly)

┌─────────────────────────────────────────────────────────────────────────┐
│ 💡 COMMON SCENARIOS                                                     │
└─────────────────────────────────────────────────────────────────────────┘

  Scenario 1: SEMESTER FEEDBACK
  ┌─────────────┬────────────────────────────────────────────────────────┐
  │ Start       │ Jan 1, 2026 00:00                                      │
  │ End         │ Jan 15, 2026 23:59                                     │
  │ Grace       │ 48 hours                                               │
  │ Result      │ Opens Jan 1, Closes Jan 17 (with grace)                │
  └─────────────┴────────────────────────────────────────────────────────┘

  Scenario 2: ALWAYS AVAILABLE
  ┌─────────────┬────────────────────────────────────────────────────────┐
  │ Start       │ (leave empty)                                          │
  │ End         │ (leave empty)                                          │
  │ Grace       │ 0                                                      │
  │ Result      │ No restrictions, available anytime                     │
  └─────────────┴────────────────────────────────────────────────────────┘

  Scenario 3: URGENT SURVEY (24 HOURS)
  ┌─────────────┬────────────────────────────────────────────────────────┐
  │ Start       │ Today 14:00                                            │
  │ End         │ Tomorrow 14:00                                         │
  │ Grace       │ 2 hours                                                │
  │ Result      │ 24-hour window + 2h grace = 26 hours total             │
  └─────────────┴────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ 🛠️ COMMANDS                                                             │
└─────────────────────────────────────────────────────────────────────────┘

  Run migration (one-time):
    php artisan migrate --force

  Send reminders manually:
    php artisan feedback:send-reminders

  Check scheduler:
    php artisan schedule:list

  Setup cron job (production):
    * * * * * cd /path-to-project && php artisan schedule:run >> /dev/null 2>&1

┌─────────────────────────────────────────────────────────────────────────┐
│ 🆘 TROUBLESHOOTING                                                      │
└─────────────────────────────────────────────────────────────────────────┘

  Problem: Students can't access form
  → Check start_date hasn't passed yet (Upcoming badge)

  Problem: Students can still submit after deadline
  → Check end_date + grace_period_hours calculation

  Problem: No reminders being sent
  → Run: php artisan feedback:send-reminders manually
  → Verify cron job is configured

  Problem: Status badges not updating
  → Clear cache: php artisan cache:clear
